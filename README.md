# CodeAlpha Email Extractor
## Project Description
This project is a simple Python script that extracts email addresses from a text file and saves them into a separate text file.
## Features
- Reads data from a text file
- Finds email addresses using regular expressions
- Displays the extracted email addresses
- Saves the extracted emails into a separate file
- Counts the total number of email addresses found
## Technologies Used
- Python
- Regular Expressions (re)
- File Handling
## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Make sure `emails.txt` is in the same folder as `email_extractor.py`.
5. Open the terminal.
6. Run: python email_extractor.py
